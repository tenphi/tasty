Ship an agent harness for [harnesspm](https://www.npmjs.com/package/@tenphi/harnesspm) in `harness/`. Apps get a short always-on style rule, an index of the docs of the installed version (`docs/llms.txt`), and the `tasty:styles` tool, which prints the CSS a styles object produces after `--setup` modules load the app's `configure()`, and warns about values that stayed unresolved.
